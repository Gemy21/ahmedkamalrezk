# Ahmed Kamal — GitHub profile README package

## Install it

1. Create a **public** GitHub repository named exactly `ahmedkamalrezk`.
2. Upload the contents of this folder to the repository root (including the hidden `.github` folder).
3. Ensure the repository's default branch is `main`.
4. Open **Settings → Actions → General → Workflow permissions** and allow read/write permissions if the workflow cannot push.
5. The built-in `GITHUB_TOKEN` secret is used automatically. No personal token is needed for this workflow.
6. Open **Actions → Update profile graphics → Run workflow** once to generate the live SVGs. The workflow then runs daily.

The initial `contributions.svg` and `stats.svg` files are placeholders only if generated by the workflow; run the workflow to replace them with live data.

## Files

- `README.md` — profile page content.
- `assets/profile-art.svg` — custom terminal banner.
- `assets/ahmed-ascii.svg` — small terminal-style illustration.
- `assets/contributions.svg` — generated contribution calendar.
- `assets/stats.svg` — generated GitHub stats.
- `scripts/generate_profile.py` — fetches GitHub GraphQL data and writes the SVGs.
- `.github/workflows/update-profile.yml` — scheduled daily update.

## Notes

The profile repository name must match the username exactly for GitHub to display its README on the profile. Keep the SVGs and scripts in the same repository so the relative image paths work.
